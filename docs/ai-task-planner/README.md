## Feasibility findings (desk research, 2026-09-25; nothing verified on the owner's laptop)

This cloud session cannot reach the owner's laptop, accounts or calendar. Every
item below is documentation evidence, not integration evidence.

| Integration | Finding | Consequence |
|---|---|---|
| ChatGPT history (required) | No official API or connector lets a consumer ChatGPT plan read its own chat history programmatically. The OpenAI API is billed separately and cannot read chatgpt.com chats. The official data export is manual and emailed (help center: up to days; link expires after 24 h). The macOS desktop app encrypts its local store. Scraping the web app is prohibited by OpenAI's Terms. | **D22.** A daily unattended ChatGPT read has no supported path today. The owner must choose the route; none is selected here. |
| Claude history (optional) | Claude.ai export is manual. Claude Code writes local JSONL transcripts, but its docs call the format internal and unstable. | Optional source; complexity is weighed under D9/D20. |
| Wispr Flow | Its local SQLite store (`flow.sqlite`) appears in Wispr's uninstall and delete-data articles, but the schema is undocumented. It may need macOS Full Disk Access. | Readable with owner permission. Parsers can break on app updates. The store is sensitive: it holds dictation from all apps (D20). |
| Runtime AI | `codex exec` (ChatGPT plan sign-in) and `claude -p` (Claude plan; not `--bare`) are official non-interactive modes and share the plan's usage limits. A local model costs nothing but quality depends on hardware. | **D23.** None is verified on the owner's machine. A subscription must be shown to work programmatically before it is relied on. |
| Google Calendar | The API is free within quota. A desktop OAuth client can use `calendar.events`. In "Testing" mode, refresh tokens expire after 7 days. A client-supplied event `id` makes creation idempotent: a duplicate returns 409. `sendUpdates=none` sends no invitation emails. | **D26**, D12b. Idempotent IDs support R10. |
| 20:00 scheduling | macOS launchd runs a missed job on wake; Windows Task Scheduler can "run as soon as possible" after a miss. A powered-off laptop runs nothing. | D21 decides catch-up and late-input behaviour. |
| Clickable pop-ups | Browser notifications from a localhost UI support action buttons through a service worker, but the browser must be running. OS-native options need helpers (alerter on macOS, toast plus a protocol handler on Windows). | D7 decides the surface. |
